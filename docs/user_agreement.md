# 光序 用户协议

**更新日期：** 2026年11月10日

欢迎使用由 **Lumaris Team** 开发和运营的光序。使用本应用前，请阅读本协议及隐私协议。不同意相关条款时，请停止使用应用或相应功能。

## 一、服务内容与可用性

光序提供校园信息服务，包括课表管理与导入、成绩和绩点、考试安排、培养方案、校车、电费及校园卡等功能。功能是否显示和可用取决于所选学校、学校配置、登录状态、设备平台及相关服务的支持情况；并非所有学校均提供上述功能。

部分功能需要有效的学校账号、网络连接或校园网环境。应用展示的数据以学校和相关服务的官方信息为准；服务可能因维护、网络或第三方系统变更而不可用。

## 二、账号、数据与课表导入

使用教务或校园卡功能时，您应有权使用所提供的账号和信息，并妥善保管凭据。应用会将您输入的登录信息发送至所选学校配置的 API 服务，具体数据处理方式见隐私协议。请确认学校和服务地址，并避免向不可信的网页提供账号密码。

您可以在未登录应用的情况下使用课表导入功能，在内嵌网页中登录教务系统并主动导入课程。应用根据当前页面提取并保存课程数据，解析结果可能受学校系统、页面结构和适配情况影响，请自行核对。

在支持的非 iOS 平台，“适配仓库导入”会从第三方拾光适配仓库下载适配器并在网页内执行，以读取课程数据。iOS 版本使用随应用发布的固定适配器快照，适配内容随应用版本更新。第三方仓库、教务网站及其适配器的可用性可能变化。

## 三、使用规范

您应遵守适用法律法规及学校、相关服务的使用规则，不得通过本应用访问无权访问的数据，不得干扰服务、利用漏洞或实施其他未经授权的操作。发现安全问题时，请通过下方渠道联系我们，避免公开披露敏感信息。

## 四、知识产权与第三方服务

本应用源代码按照项目仓库中的开源许可证提供；第三方依赖和适配器适用各自的许可证。应用名称、图标及学校相关标识的权利归各自权利人所有。

第三方服务及内容由相应提供方负责。使用第三方网页或服务时，您还应遵守其适用条款。

## 五、服务变更与责任

我们可能根据学校系统、技术条件和维护情况调整、中断或停止部分功能。应用按现状提供，课程、成绩等结果仅供参考。因学校系统、第三方服务或网络故障造成的中断和数据差异，请以相关官方服务的信息为准。本协议不排除适用法律不允许排除的权利或责任。

我们可能根据功能、服务或适用要求更新本协议，并通过应用提供的协议页面发布更新版本。请在使用相关功能前阅读最新协议。
