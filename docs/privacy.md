# 光序 隐私协议

**更新日期：** 2026年11月10日

欢迎使用光序。本应用由 **Lumaris Team** 开发和运营。本协议介绍使用应用时可能涉及的信息处理；学校、登录状态、平台和您选择的功能不同，实际处理的信息也会有所不同。

## 一、我们处理的信息及用途

- **学校与账号信息**：您选择的学校和登录方式用于确定可用功能和服务地址。使用教务登录时，您输入的学号、密码会发送至所选学校配置的教务 API 服务，用于身份认证和获取数据。该服务地址不一定是学校官方服务器，具体由学校配置决定。凭据也会保存在设备上，以支持后续登录；应用使用平台安全存储保存凭据，部分平台可能使用本地存储作为兼容方案。
- **教务与校园生活数据**：使用相应功能时，应用通过所选学校的 API 服务获取并展示课表、成绩、考试、培养方案、电费、校园卡等数据，并在设备上缓存部分结果。校园卡功能可能需要您提供卡号或密码，并将其发送至相应 API 服务。
- **课表导入**：您可在应用内打开教务系统网页，登录后主动导入课表。应用读取当前页面的内容以解析课程，并在设备上保存导入结果；网页的登录、Cookie 和其他数据处理也受该网页运营方的规则约束。请只在信任的网站输入账号密码。
- **学校目录与配置**：应用从光序基础服务获取学校目录和功能配置。学校、登录状态及服务配置可能影响功能是否显示或可用。
- **设置、缓存和小组件**：应用在设备上保存设置、课程等数据和网络响应缓存；启用小组件时，必要的课程信息会写入应用与小组件可共享的本地存储。启用课程提醒时，应用会设置本地通知。
- **位置与文件**：使用校园地图定位时，在您授权后应用会获取设备位置以显示当前位置；您可在系统设置中关闭位置权限。选择自定义背景或反馈图片时，应用会读取您主动选择的文件。
- **意见反馈**：提交反馈时，您填写的内容、联系方式、所选学校和您选择附加的图片会发送至反馈服务，用于处理反馈；请避免提交不必要的敏感信息。
- **网络与诊断信息**：访问服务时，服务提供方可能接收 IP 地址、请求时间和设备或浏览器发送的必要网络信息。应用也可能在设备上记录错误和诊断信息，用于排查问题。请勿在反馈中提供密码等敏感信息。

## 二、课表适配仓库和第三方服务

在支持的非 iOS 平台，选择“适配仓库导入”时，应用会从 GitHub 或 Gitee 下载拾光适配仓库的索引和脚本，在内嵌网页中运行所选适配器以提取课程。iOS 版本使用随应用打包的适配仓库快照，更新快照需要更新应用。仓库及适配器由第三方维护，各平台的适配器脚本均可能与教务网页或其配置的服务交互。

学校 API 服务、您访问的教务网站、GitHub、Gitee 及其他您主动使用的外部服务可能独立处理相关信息；其数据处理、保存期限和安全措施由相应服务提供方决定。应用更新检查在支持的平台连接更新服务。我们建议您查阅相关服务的隐私说明。

## 三、存储、安全与删除

应用会在设备上保存凭据、设置和部分业务数据，直到您退出登录、清除相关缓存、删除数据或卸载应用；不同操作清除的范围可能不同，清除缓存通常不会退出登录。网页 Cookie、小组件共享数据、系统备份以及服务端保存的数据可能需要通过相应系统设置或服务提供方另行处理。

我们使用平台提供的安全存储等措施保护设备上的凭据，并在可用时通过加密连接访问服务。用户自填网址及学校提供的服务地址可能具有不同的安全条件，无法保证所有第三方连接均已加密。

您可以通过退出登录停止使用登录功能、通过设置清除缓存，或卸载应用停止使用。要查询、更正或删除服务端数据，以及撤回对应服务的数据处理授权，请联系相应服务提供方；也可通过下方方式联系我们协助处理。撤回同意不影响撤回前已进行的处理。

## 四、未成年人

本应用主要面向高校学生。未满 18 周岁的用户应在监护人指导下阅读本协议并使用应用；涉及学校或第三方服务时，还应遵守其相关规定。

## 五、协议更新与联系我们

我们可能根据功能和数据处理情况更新本协议。更新版本会通过应用提供的协议页面发布；请在使用相关功能前阅读最新内容。

如对本协议或个人信息处理有疑问、意见或请求，可联系 Lumaris Team，或通过 [项目仓库](https://gitee.com/luckyfishisdashen/iOSClub.AppMobile)提交反馈。请勿公开提交密码或其他敏感信息。
